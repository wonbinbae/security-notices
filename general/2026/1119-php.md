# [보안공지] PHP 제품 보안 업데이트 공지

게시일 2026-11-19

## 개요

■ PHP 프로젝트는 취약점을 해결한 보안 업데이트 발표 [1]  
■ 영향받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

■ PHP-FPM에서 발생하는 읽지 않은 HTTP 요청 본문 처리 미흡으로 요청 밀반입(Request Smuggling)을 통한 원격 코드 실행이 가능한 취약점(CVE-2026-129289) [2]  
■ PHP에서 발생하는 세션 업로드 진행률 기능의 직렬화 형식 불일치로 원격 코드 실행이 가능한 취약점(CVE-2026-115560) [2]  
■ PHP에서 발생하는 타임존 캐시 해제 후 사용(Use-After-Free)으로 원격 코드 실행이 가능한 취약점(CVE-2026-129496) [2]  
■ PHP에서 발생하는 세션 파일 쓰기 중단 시 일부만 덮어써진 세션의 역직렬화로 원격 코드 실행이 가능한 취약점(CVE-2026-126714) [2]  
■ PHP에서 발생하는 매직 메서드(__call, __callStatic) 백트레이스 수집 중 해제 후 사용(Use-After-Free)으로 원격 코드 실행이 가능한 취약점(CVE-2026-129474) [2]  
■ PHP에서 발생하는 종료 처리 후 치명적 오류 백트레이스 재생성으로 인한 해제 후 사용(Use-After-Free)으로 메모리 손상이 가능한 취약점(CVE-2026-129182) [2]  
■ PHP에서 발생하는 세션 종료 중단 후 해제 후 사용(Use-After-Free)으로 메모리 손상이 가능한 취약점(CVE-2026-129481) [2]  
■ PHP-FPM에서 발생하는 epoll 이벤트 처리 중 해제 후 사용(Use-After-Free)으로 권한 상승이 가능한 취약점(CVE-2026-129291) [2]  
■ PHP에서 발생하는 여러 줄로 접힌 HTTP 응답 헤더 처리 중 자원 과다 사용으로 서비스 거부가 가능한 취약점(CVE-2026-127960) [2]  
■ PHP에서 발생하는 대문자가 포함된 HTTPS, FTPS URL 스킴 처리 미흡으로 평문 전송에 따른 정보 노출이 가능한 취약점(CVE-2026-128064) [2]  
■ PHP에서 발생하는 PHAR 서명 알고리즘 다운그레이드로 OpenSSL 서명 검증 우회가 가능한 취약점(CVE-2026-128090) [2]  
■ PHP-CGI에서 발생하는 PATH_INFO 보정 중 경계 밖 읽기 및 쓰기로 메모리 손상이 가능한 취약점(CVE-2026-129538) [2]  
■ PHP에서 발생하는 SOAP DTD 엔티티 참조 처리 중 해제 후 사용(Use-After-Free)으로 메모리 손상이 가능한 취약점(CVE-2026-129506) [2]  
■ PHP에서 발생하는 DOM XML 직렬화 중 이중 해제(Double Free)로 메모리 손상이 가능한 취약점(CVE-2026-129501) [2]  
■ PHP에서 발생하는 SOAP 배열 차원 값 처리 미흡으로 정보 노출이 가능한 취약점(CVE-2026-15353) [2]  
■ PHP에서 발생하는 대용량 입력의 RFC 3986 URI 직렬화 오류로 잘못된 URI 생성이 가능한 취약점(CVE-2026-129438) [2]  
■ PHP-FPM에서 발생하는 상태 페이지(status) 출력값 미처리로 크로스 사이트 스크립팅(XSS)이 가능한 취약점(CVE-2026-129292) [2]

※ CVE-2026-126714(phpAfterShell)는 세션 업로드 진행률 기능(`session.upload_progress.enabled`, 패치 이전 버전 기본 활성화)과 기본 세션 저장 방식(`files`)을 사용하는 경우, 인증 없이 multipart 요청만으로 세션 파일 조작이 가능하며 업로드 기능이나 `session_start()` 호출이 없는 경로로도 도달 가능 [2][3]  
※ CVE-2026-126714로 조작된 세션은 이후 `session_start()` 호출 시 역직렬화되며, 벤더는 애플리케이션 가젯 체인이 필요하다고 기술하였으나 발견자는 PHP 내장 클래스만으로 원격 코드 실행을 시연 [2][3]  
※ CVE-2026-126714는 기존 PHP2Shell 패치를 우회하는 취약점으로, 원격 코드 실행 외에 인증, 권한, CSRF 토큰 등 세션 값 변조에도 악용 가능 [3]  
※ CVE-2026-129289는 웹서버가 PHP-FPM, LSAPI 백엔드 연결을 재사용하도록 설정된 경우(nginx `fastcgi_keep_conn on`, Apache `mod_proxy_fcgi` `enablereuse=on` 등)에 해당 [2]  
※ CVE-2026-115560은 세션 업로드 진행률 기능이 활성화되어 있고 세션을 쓰는 쪽과 읽는 쪽의 `session.serialize_handler`가 다른 경우에 해당 [2]  
※ CVE-2026-129474, CVE-2026-129182는 PHP 8.5에만 해당 [2]

※ 즉시 업데이트가 어려운 경우 아래 임시 조치 적용 후 PHP 프로세스 재시작 권고 [2]  
　- CVE-2026-126714, CVE-2026-115560: 업로드 진행률 기능을 사용하지 않으면 `session.upload_progress.enabled=0` 설정 (단, 세션에 외부 입력을 대량 저장하는 애플리케이션은 CVE-2026-126714 위험이 남으므로 업데이트 필요)  
　- CVE-2026-129289: 웹서버의 PHP-FPM, LSAPI 백엔드 연결 재사용 비활성화  
　- CVE-2026-129474, CVE-2026-129182: `fatal_error_backtraces=0` 설정 (CVE-2026-129474는 `zend.exception_ignore_args=1`로도 완화 가능)  
※ CVE-2026-115560 패치 버전부터 세션 업로드 진행률 기능이 기본 비활성화되나, 설정에서 명시적으로 활성화한 경우 그대로 유지되므로 설정 확인 필요 [2]  
※ 리눅스 배포판 등에서 제공하는 PHP 패키지는 버전 번호 변경 없이 패치가 반영될 수 있으므로 해당 배포판의 보안 공지 기준으로 판단 [3]  
※ PHP 8.1 이하 지원 종료(EOL) 버전은 패치 미제공, 지원 버전으로 업그레이드 후 패치 적용 권고 [1]
